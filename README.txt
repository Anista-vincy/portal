HOSPITAL EMERGENCY QUEUE VISUALIZER - PYTHON VERSION

This version uses Python instead of JavaScript.
It uses only Python's built-in libraries.
No Flask, Node.js, JavaScript, or extra Python packages are required.

HOW TO RUN:
1. Extract the ZIP.
2. Open the extracted folder.
3. Click the File Explorer address bar.
4. Type cmd and press Enter.
5. Run: python app.py
   If that does not work: py app.py
6. Keep the Command Prompt window open.
7. Open Edge/Chrome and visit:
   http://127.0.0.1:5000

FEATURES:
- Add emergency patients
- Priority Queue using Python
- Priority 1 = Critical
- Priority 2 = Serious
- Priority 3 = Moderate
- Priority 4 = Stable
- Same-priority patients are treated in arrival order
- Treat Next Patient
- Load Demo Patients
- Clear All
- Queue statistics

No JavaScript is used.
